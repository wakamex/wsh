v0.3.1 fixes installed profiling and an early-startup terminal-query delay. Your existing configuration and theme selection continue to work.

- `wsh profile` and `wsh profile --functions` now load Zsh modules from the installed bundle before profiling begins. They no longer depend on the original build directory being present. ([`2d69d55`](https://github.com/wakamex/wsh/commit/2d69d55))
- Wsh applies its default terminal-query policy before user `.zshenv` can load ZLE through completion initialization. This prevents an unintended query wait in configurations such as SDKMAN startup. Explicit user terminal policies and the launch-environment query opt-in remain supported. ([`2239f59`](https://github.com/wakamex/wsh/commit/2239f59))
- A matched comparison of both fixes passed the unchanged 3 ms p90 profiling-overhead gate in all six runs, retaining 600 normal/profile pairs. ([Results](https://github.com/wakamex/wsh/blob/v0.3.1/benchmarks/profile-order-investigation-2026-09-06/report.md))

Update an existing installation with:

```sh
wsh update
```
