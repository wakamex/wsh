# Wsh 0.4.8

Wsh now builds and passes its full test suite on macOS and Ubuntu, and installs on macOS, or on Linux with [Homebrew](https://brew.sh/), with `brew install wakamex/tap/wsh`. Pane history now works when the state directory sits under a symlinked folder, as `/home` does on Fedora Atomic desktops.

## Changes

- Homebrew: the new `wakamex/tap` formula builds Wsh from this release's source archive, `wsh-v0.4.8-source.tar.gz`, now attached to the release and listed in `SHA256SUMS`. A CI job installs and tests the formula on macOS for every commit. To make Wsh your login shell, add `$(brew --prefix)/bin/wsh` to `/etc/shells` and run `chsh`, as the install message shows. ([4fd35b9](https://github.com/wakamex/wsh/commit/4fd35b9), [44c6836](https://github.com/wakamex/wsh/commit/44c6836))
- Pane history never started when a folder above its state directory was a symlink, such as `/home` on Fedora Atomic or `/var` on macOS; commands then went only to the shared history file. Symlinked parent folders now work, and the pane folder itself must still be a real, private folder. ([c95c8a7](https://github.com/wakamex/wsh/commit/c95c8a7))
- Wsh recognizes a plugin checked out from GitHub through its Git history without the `timeout` command, which macOS lacks. On a Mac such plugins were treated as unknown and kept their slower original code. ([3d98f6d](https://github.com/wakamex/wsh/commit/3d98f6d))
- Wsh started through a symlink, as Homebrew installs it, finds its own files. ([4fd35b9](https://github.com/wakamex/wsh/commit/4fd35b9))
- Building from source: Wsh builds with each system's own compilers and libraries on macOS 15 and Ubuntu 24.04, and release checks now require both, alongside the Fedora and glibc 2.28 builds. [DEVELOPMENT.md](https://github.com/wakamex/wsh/blob/v0.4.8/DEVELOPMENT.md#native-development-installation) lists the packages each system needs. ([1474cd2](https://github.com/wakamex/wsh/commit/1474cd2), [0310521](https://github.com/wakamex/wsh/commit/0310521), [97f1615](https://github.com/wakamex/wsh/commit/97f1615))
- Tests: the suite no longer assumes Linux, adds checks that typed-ahead input is never lost and that a symlinked start works, and two upstream Zsh tests that depended on timing or hash order are fixed with test-only patches. ([e16b639](https://github.com/wakamex/wsh/commit/e16b639), [258797a](https://github.com/wakamex/wsh/commit/258797a), [13b1332](https://github.com/wakamex/wsh/commit/13b1332), [d494ef9](https://github.com/wakamex/wsh/commit/d494ef9))

## Installation and upgrade

Fedora 44 x86-64 users with the [COPR repository](https://copr.fedorainfracloud.org/coprs/wakamex/wsh/) enabled can update with `sudo dnf upgrade --refresh wsh`. Homebrew users install with `brew install wakamex/tap/wsh` and update with `brew upgrade wsh`. Shells started before an upgrade keep the previous behavior until they are restarted.
