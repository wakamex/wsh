v0.2.0 makes Wsh usable as a daily interactive shell while preserving existing Zsh configuration. It adds three measured editing defaults, compatibility diagnostics, exact foreground application startup, native terminal integration, and a tested post-5.9 Zsh build.

## Highlights

- Existing `.zshenv`, `.zprofile`, `.zshrc`, and `.zlogin` files load in native order, including Oh My Zsh setups. Wsh installs its integration afterward without parsing or rewriting user configuration. ([`f8cc473`](https://github.com/wakamex/wsh/commit/f8cc47351a0ab6f98eed538d95202aab1bbbd6fc))
- History substring search, autosuggestions, and syntax highlighting are bundled and enabled by default. Exact upstream copies are replaced safely, while modified or unknown implementations remain active. ([history search](https://github.com/wakamex/wsh/commit/2b964dd7def56eb591cbb22613816c74bbdd7069), [autosuggestions](https://github.com/wakamex/wsh/commit/a51399f902ce416aeb5060a97b2ab9a743bf6aa0), [syntax highlighting](https://github.com/wakamex/wsh/commit/c5441fb8cd3ee06514d17db1c89a583cc905d1e4))
- `wsh doctor` reports exact redundant plugin declarations that can be removed and preserves ambiguous implementations without editing startup files. ([`c62001d`](https://github.com/wakamex/wsh/commit/c62001d2fd72a56a275ec29ac0c6126bfb02d3dc))
- Bare `wsh` starts the active shell. `wsh -- <command> [arguments...]` starts an exact argument vector with native Zsh foreground process groups, Ctrl-C, Ctrl-Z, `fg`, terminal restoration, and one prompt afterward. ([bare launch](https://github.com/wakamex/wsh/commit/2a7bda4447805757f49c4bb8448c5391290ae099), [foreground startup](https://github.com/wakamex/wsh/commit/9037627f6622c5d0b90e873fc67a954c33e0d253))
- The bundled Zsh emits OSC 7 working-directory reports and OSC 133 prompt and output boundaries without an injected terminal hook framework. ([`7fefaa6`](https://github.com/wakamex/wsh/commit/7fefaa6b7083c3fd174536b240a2dc94005a79d3))
- The bundle advances from Zsh 5.9.2 to a pinned upstream revision containing 1,074 later `master` commits. It passed the upstream suite and Wsh's complete compatibility, correctness, resource, and performance gates. ([`1ff7b2d`](https://github.com/wakamex/wsh/commit/1ff7b2dc28c5e6af4574c474b75a3447d6448e95))
- Official builds now use a frozen, digest-pinned Rocky Linux 8.10 builder. Two isolated glibc 2.28 builds must produce byte-identical release outputs before publication. ([builder](https://github.com/wakamex/wsh/commit/69cbb008b0346834512a5e1378c91a7bc8ddae62), [release hardening](https://github.com/wakamex/wsh/commit/bef762fb0e8b5553a45cba338ba2fc7bd382cc8b))

## Install or update

Existing installations can update atomically and retain offline rollback:

```sh
wsh update
```

Install the latest release on x86-64 Linux with glibc 2.28 or newer:

```sh
curl --proto '=https' --tlsv1.2 -fsSL https://github.com/wakamex/wsh/releases/latest/download/wsh-install.sh | sh
```
