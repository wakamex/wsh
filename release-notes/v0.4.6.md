# Wsh 0.4.6

Reloading your configuration with `source ~/.zshrc` no longer breaks Enter and Space when it loads [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions), for example through Oh My Zsh. Up and Down now search history for what you have typed without Oh My Zsh. A shared `.zshrc` can test `WSH_VERSION` to tell whether Wsh is reading it.

## Changes

- Running `source ~/.zshrc` in a shell whose configuration loads zsh-autosuggestions used to leave Enter and Space doing nothing until the shell exited. Wsh now hands autosuggestions to the reloaded plugin at the next prompt, restoring the editor keys it had wrapped, so the reloaded plugin works as it does in plain Zsh for the rest of that session. New shells use Wsh's built-in autosuggestions again. ([c8cb8de](https://github.com/wakamex/wsh/commit/c8cb8de))
- Up and Down search history for what you have typed in every terminal key mode. Without Oh My Zsh, which switches terminals into the mode Wsh previously expected, they moved through history one line at a time. Bindings you set yourself are kept. ([7e38e75](https://github.com/wakamex/wsh/commit/7e38e75))
- Wsh sets `WSH_VERSION` to its version before any startup file runs and does not pass it to programs it starts, so a regular Zsh started from Wsh does not see it. [THEMES.md](https://github.com/wakamex/wsh/blob/v0.4.6/THEMES.md#session-selection-and-shared-configuration) shows how a shared `.zshrc` uses it to select Wsh's prompt in Wsh and keep the Oh My Zsh theme in regular Zsh. ([e27b1f1](https://github.com/wakamex/wsh/commit/e27b1f1))
- Maintenance: the installation check prints a failing test's output ([bbd540c](https://github.com/wakamex/wsh/commit/bbd540c)), the source package integrity check reads the whole package before unpacking it ([72a239a](https://github.com/wakamex/wsh/commit/72a239a)), the plan for making Oh My Zsh removable is recorded ([c07b1da](https://github.com/wakamex/wsh/commit/c07b1da)), and the 0.4.5 publication is recorded ([d262ef0](https://github.com/wakamex/wsh/commit/d262ef0)).

## Installation and upgrade

Fedora 44 x86-64 users with the [COPR repository](https://copr.fedorainfracloud.org/coprs/wakamex/wsh/) enabled can update with `sudo dnf upgrade --refresh wsh`. Shells started before the upgrade keep the previous behavior until they are restarted.
