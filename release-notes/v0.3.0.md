v0.3.0 adds directory jumping, selectable prompt themes, and profiling to help find shell slowdowns. It also changes the default prompt behavior: Wsh now preserves the prompt from your existing configuration unless you select a Wsh theme.

## Highlights

- Jump back to visited directories with built-in `z`, ranked by frequency and recency. Existing OMZ, zoxide, and custom commands remain in charge. The bundled implementation uses OMZ Zsh-z's data format and settings. ([`511fc55`](https://github.com/wakamex/wsh/commit/511fc557a65d3d7d760f746a02427f98c9de05b6))
- Choose Minimal, Wakamex, Robbyrussell, or Agnoster through `WSH_THEME`, or load a custom TOML definition. All four use Wsh's asynchronous Git collector. The Robbyrussell and Agnoster ports are data-only presentations; their supported components are documented in the [theme guide](https://github.com/wakamex/wsh/blob/v0.3.0/THEMES.md). ([`511fc55`](https://github.com/wakamex/wsh/commit/511fc557a65d3d7d760f746a02427f98c9de05b6))
- Run `wsh profile` to see startup-file, built-in feature, Git, and prompt timing after an interactive session. Add `--functions` for Zsh function timing, or use `wsh profile report` to recover a retained session's report. Default traces exclude command text and user paths. ([`3decf52`](https://github.com/wakamex/wsh/commit/3decf521a13d98b9e0f50c64c666766406800205))
- `wsh doctor` now suggests cleanup when an OMZ theme loads alongside Wsh's selected prompt. Plugin advice accounts for users who also run regular Zsh, and doctor continues to leave configuration files untouched. ([`511fc55`](https://github.com/wakamex/wsh/commit/511fc557a65d3d7d760f746a02427f98c9de05b6))
- `wsh version` reports the active bundle, Wsh and Zsh source revisions, target, and bundle digest. `wsh --version` remains the short launcher-version command. ([`a8a4a6a`](https://github.com/wakamex/wsh/commit/a8a4a6a24ed286356bcf931ac40f174350cd43d2))
- Release verification can resume after publication without replacing immutable assets or their original provenance. ([`cdb1b51`](https://github.com/wakamex/wsh/commit/cdb1b5129dc0b1d66a01e4e31bb7e3e79aaddf99))

## Prompt selection when upgrading

With `WSH_THEME` unset or empty, Wsh keeps your existing prompt. To retain Wsh's minimal prompt, launch it with:

```sh
WSH_THEME=minimal wsh
```

Replace `minimal` with `wakamex`, `robbyrussell`, or `agnoster` to choose another presentation. Editing features and directory jumping work independently of prompt selection. Agnoster requires a terminal font with Powerline separator glyphs.

Selecting a Wsh theme does not stop OMZ from loading its theme. That duplicate work can remain while you use both shells; the [shared-configuration guide](https://github.com/wakamex/wsh/blob/v0.3.0/README.md#prompt-selection) explains the optional conditional that skips it. Missing or invalid Wsh theme definitions leave the startup prompt in place with a diagnostic.

## Install or update

Existing installations can update with:

```sh
wsh update
```

Install on x86-64 Linux with glibc 2.28 or newer:

```sh
curl --proto '=https' --tlsv1.2 -fsSL https://github.com/wakamex/wsh/releases/latest/download/wsh-install.sh | sh
```
