# Wsh 0.4.2

Fixes `wsh --doctor` timing out after ten seconds when run from an interactive terminal, even with an empty configuration. Doctor now completes without the `setsid --wait` workaround.

The diagnostic child now starts without a controlling terminal, preventing Zsh's job control from stopping it during startup. Real-terminal regressions cover reporting, background-child cleanup, interruption and timeout. The fix passed the complete installed suite and upstream tests on the glibc 2.28 floor. See the [regression evidence](https://github.com/wakamex/wsh/blob/cbc8687/benchmarks/doctor-terminal-2026-09-27/report.md).
