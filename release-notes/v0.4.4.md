# Wsh 0.4.4

Recognizes the `z` plugin in the latest Oh My Zsh as an official copy, so its directory jumping runs on Wsh's native implementation whether Oh My Zsh was installed through Git or copied in some other way.

## Changes

- Oh My Zsh updated its bundled [zsh-z](https://github.com/agkozak/zsh-z) to fix creating its data and lock files when `NO_CLOBBER` is set. Wsh now catalogs that exact version. Wsh's own implementation creates those files directly and was not affected; Git checkouts of Oh My Zsh were already recognized through their official commit. ([d5f6181](https://github.com/wakamex/wsh/commit/d5f6181))
- Each version is now released on GitHub and COPR from the same tagged commit. ([1ad138a](https://github.com/wakamex/wsh/commit/1ad138a))
- Record the COPR 0.4.3 publication and its signed-package checks. ([40ec6a7](https://github.com/wakamex/wsh/commit/40ec6a7))

## Installation and upgrade

Fedora 44 x86-64 users with the [COPR repository](https://copr.fedorainfracloud.org/coprs/wakamex/wsh/) enabled can update with `sudo dnf upgrade --refresh wsh`. Shells started before the upgrade keep the previous catalog until they are restarted.
