# Native foreground startup comparison

The native foreground option should preserve exact argument bytes and keep the current Zsh process as the job-table owner. The observed maintenance cost is the existing one-shot precmd callback, exported handoff state, and shell implementation of terminal marker policy. The baseline is native tools at 577241d with the accepted startup adapter and current Rust foreground command. The smallest C candidate captures argv in the dispatcher, starts normal interactive Zsh, and executes a fixed parameter expansion through Zsh with its native ZLE pre/post-execution marker calls. It does not reconstruct command source from argument values.

The hypothesis is that a native startup action can remove the callback and duplicated marker-policy loop while preserving shell behavior. The action must isolate emulation options as the current callback does. Compare it before changing ordinary startup or package layout. Keep the legacy callback available for the legacy manager until its callers migrate.

Correctness precedes timings: exact bytes including non-UTF-8 and empty values, aliases/functions, nonzero status, startup-file order, login and non-login modes, native script delimiters, Ctrl-C, applications consuming Ctrl-C, Ctrl-Z, fg, prompt return, terminal settings, user hooks and enabled/disabled OSC markers. Reuse the existing foreground probe and PTY suite with only invocation migration, and retain the original fixture. Use the primary native prompt marker as readiness. Add a sanitizer run for the new C interface.

Measure 50 alternating matched invocations after correctness with trace disabled and identical global startup policy, resources and runtime. Compare time to the first editable prompt after an immediately exiting foreground probe. The fixed gate is +3 ms paired p95; retain all samples and failed runs. Allow at most two interventions or three hours on this hypothesis before auditing the premise. A larger native action that duplicates job or editor lifecycle logic will remain a prototype even if its timings pass.
