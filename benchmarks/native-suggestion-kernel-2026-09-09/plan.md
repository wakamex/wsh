# Compare autosuggestion history selection

Start from `4cf9d07`. Autosuggestions already uses native history pattern matching but escapes the prefix through a shell pattern replacement. The upstream source explicitly identifies Zsh's `(b)` quoting flag as a smaller replacement once old Zsh versions are no longer supported. Compare the unchanged strategy, this builtin-only counterfactual, and a private C strategy that calls the same quoting, pattern and history APIs directly. Keep async cancellation, widgets, acceptance, stale-result handling and plugin ownership in the existing component.

Require exact suggestion parity against the pinned implementation for literal metacharacters, Unicode, multiline commands, empty and absent prefixes, history changes and ignore patterns. Test the C strategy under sanitizers before timing. Use 50 alternating samples per implementation at 100 and 10,000 real history entries, with recent-match and absent-prefix workloads. Require no more than +1 ms paired p95 regression. A C interface must reduce the 10,000-entry median by at least 20% beyond the builtin-only counterfactual to justify its retained responsibilities. Record any compatibility differences and keep a partial strategy prototype separate from a complete editor-component adoption. Stop after two failed interventions or two hours at a gate.
