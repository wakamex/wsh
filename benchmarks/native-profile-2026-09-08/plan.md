# Native profile invocation and reporting

The locked native shell at c4ac10f still lacks its declared profile commands. The baseline Rust manager creates private profile storage, injects the current Zsh instrumentation, and reports JSON events through a 642-line Rust reporter; the shell adapter is 115 lines. The first bounded candidate moves invocation and reporting into C while holding the existing instrumentation and runtime boundary fixed. It uses the maintained system Jansson library for strict JSON decoding, including duplicate-key and encoding rejection, instead of introducing a handwritten JSON parser. Count this library and remaining adapter in the complete implementation comparison.

Native invocation preserves exact Zsh arguments, startup semantics, command exit status, and optional function profiling. Storage is created only for an explicit profile command. New metadata records compiled native identity without requiring an installed per-user bundle or activation state. Report recovery accepts both native metadata and old saved traces; legacy traces retain their recorded bundle identity and are labelled as recorded identity rather than claiming verification of currently installed resources. Existing profile directory, event, trace-size, line-size, function-size, schema, privacy, and malformed-input limits remain gates. Preserve existing files and do not change permissions on arbitrary pre-existing parent directories.
