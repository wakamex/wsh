# Native completion initialization experiment

An empty user configuration has no `compdef` or `_comps`, so bundled command-specific completion and directory-jump completion are unavailable. Test the smallest counterfactual: initialize the bundled native completion system from a private `.zshrc` with `autoload -Uz compinit; compinit -i -d "$HOME/.zcompdump"`. Native audit remains enabled. No user configuration or installed bundle changes.

Use manager source 950bde517bdbb75d3c2a0933293b95f3d013a967 and the unsigned development bundle ccf3c17708aae1b1fc23c4170d54ff6e78a919f0adc0e0950f3590c6325c9698, whose payload contains both correctness fixes at 2239f59bee65b0a083bfb291c15e17548012f828. All variants use the identical manager, bundle, environment, observer, fixture and enabled editing defaults; preserve the user-style prompt with WSH_THEME empty. The manager and complete bundle manifest are retained by hash. No tracing is enabled.

First check real ZLE completion of a unique Git branch, a spaced directory from the z database, and a spaced filesystem path. Capture the actual editor buffer through a test widget after Tab, without executing it. The baseline must demonstrate the missing command-specific behavior, while ordinary native initialization must pass all three. Inspect existing compinit source and its insecure-directory handling rather than substituting a fake completion engine.

After correctness, run 50 fixed rounds alternating variant order: no initialization, initialization with no dump, and initialization with a previously generated dump. Cache cold means only the compdump is missing; this does not flush the operating-system page cache. Measure first-editable latency through native OSC 133 B after line-init, and first Git-branch Tab through the capture widget. Use nearest-rank p95. The eager candidate must add at most 20 ms to warm-cache first-editable p95, at most 100 ms to missing-cache first-editable p95, and finish first Git-branch Tab at p95 within 100 ms. These are feature-screening budgets, separate from the existing 3 ms profiling overhead gate.

Retain all 150 observations, correctness transcripts, build identities, fixture and harness. Do not run other local build/test/verification or tool-shell commands during timing. One eager hypothesis is allowed; stop after correctness failure or a failed timing gate. A deferred initialization design requires a separate hypothesis and checks that it preserves user widgets and the bundled editing defaults; it is not automatically authorized for adoption by an eager failure.
