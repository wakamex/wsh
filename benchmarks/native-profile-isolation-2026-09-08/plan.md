# Keep native profile traces local to their owning shell

At 3fa3951, a noninteractive native profile that runs a child native `-ic` shell collects that child's directory/history/autosuggestion/highlighting spans and shell-exit event. The parent never initialized those components. The retained real-shell baseline reproduces this with status 19 and a child status 3. Profile variables stay exported until the interactive adapter installs its hooks, so both noninteractive sessions and commands in user startup files can leak tracing into children.

The smallest correction unexports profile parameters before user startup and explicitly exports the two existing trace settings only within the runtime-start function.
