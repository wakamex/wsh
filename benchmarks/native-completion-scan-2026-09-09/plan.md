# Split native completion initialization before choosing a change

Start from `ba0f607` with the accepted native profiler and complete C-helper comparison installation. The retained deferred experiment fails the 100 ms first-Tab budget with both absent and reusable dumps. Its component clocks locate the largest cold cost inside native compinit but do not separate audit, registration scanning and dump generation.

First retain the effective fpath, source hashes and mappings from ordinary native compinit. Insert buffered timestamps at the existing compinit boundaries, keeping formatting and output after the operation. Compare ordinary and timed compinit in 50 alternating pairs per absent/reusable-dump state on CPU 0. Require identical registrations and widget behavior. Use the spans to identify large costs; retain the existing +3 ms paired p95 instrumentation threshold and treat a failed threshold as diagnostic only. Avoid assigning sub-millisecond causality from noisy spans.

Then record the measured cost and a concrete smaller counterfactual before changing initialization. Prefer a Zsh builtin transformation, existing dump or function compilation mechanism before a new C subsystem or cache authority. Any candidate must preserve compaudit's security decisions, custom fpath and compdef behavior, existing completion and widgets, vi mode and editing composition. Compare missing, reusable, stale and unusable dumps, native Git branch and spaced-path completion, directory jumping and first/second Tab. Retain the existing startup limits of +100 ms without a dump and +20 ms with one, and the 100 ms p95 first/second Tab limits. No work moved onto Tab counts as eliminated.

Use 50 alternating repetitions per final timing workload after correctness. Two interventions or four hours at a failing gate require a premise audit. A failed or inconclusive initialization experiment leaves the current default usable and records the exact remaining cost; it does not justify an automatic audit bypass or a generic completion broker.

The first split passes the +3 ms instrumentation gate: cold compinit has medians of 11.684 ms audit, 109.797 ms registration scan and 26.463 ms dump generation; warm initialization is 17.380 ms overall. Its retained effective fpath also includes the original development build directory as well as the relocated installation. The next controlled fixture explicitly selects the installed bundled function directory, consistently for every variant, so a build-tree duplicate cannot define the proposed system-package behavior. Custom fpath remains a separate correctness case.

The candidate uses an installation-provided dump generated by upstream compinit, preserving native audit and file-count/version invalidation. First test ordinary reuse, then add a private `-R` compinit option that suppresses writing/regenerating the selected dump while preserving loading and fallback scanning. This avoids treating an immutable package file as a writable user cache. Existing `-D`, `-d`, security flags and ordinary behavior keep their meanings. Generate the dump from only bundled function inputs, restore the ordinary per-user `_comp_dumpfile` after initialization, and preserve an already initialized completion system or custom Tab binding. Test the new option in a private source copy before adding it to any production source lock.

The first 300-shell comparison passes the valid installation dump at 39.645 ms startup p95 and 72.066 ms first-Tab p95, but stale/unusable fallback adds about 113 ms startup against the 100 ms limit. Preserve that failure. The next intervention changes only registration-header input in the private compinit candidate: use the existing `zsh/system` sysread builtin for a bounded 4 KiB read, split a complete first line using native array expansion, and fall back to the original read for long or incomplete headers or an unavailable module. Zsh's current zread implementation issues one-byte reads; retain syscall evidence before testing the intervention. Keep compdef, audit, dump behavior and all final workloads unchanged. Require byte-equivalent header fields across whitespace, quoting, controls, encodings and the 4 KiB boundary before repeating ZLE correctness and timing. This is the second intervention at the fallback-startup gate; failure requires a premise audit before further implementation.
