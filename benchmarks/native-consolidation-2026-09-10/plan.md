# Native distribution and editor ownership consolidation

Baseline is 1cf156c. Native shell and helper execution are C, but development assembly still requires Cargo, rustc, the legacy manifest verifier and Cargo.toml version metadata. Published releases use the previous Rust distribution. The user authorizes migration of distribution/build tooling and removal of obsolete crates, plus complete autosuggestion and substantial highlighting parser prototypes, committed separately. This authorizes local code and workflow changes, not publication or changes to account shells.

1. Build and verify a native installation without executing Rust tools. Use the existing payload layout initially and one native manifest verifier shared by assembly, packaging and native contracts. Centralize product version outside Cargo. Test malformed inventories, payload tampering, missing/extra files, symlinks and modes before a real host build and installed contracts. Preserve historical evidence against its original inputs.
2. Move system-package build, validation, reproduction and publication preparation to the native path. Keep exact-commit eligibility and deliberate tag authorization. Qualify the actual RPM, two builds and installed tests before removing legacy crates/toolchain dependencies and obsolete active workflows. Document migration and the supported Fedora RPM artifact contract.
3. Prototype complete autosuggestion ownership, including asynchronous result lifecycle and widget registration, against the pinned plugin's real ZLE behavior. Require correctness and sanitizer parity before 50 paired complete editing sequences. Preserve the existing +1 ms paired p95 regression gate; either meet the existing 20% whole-sequence improvement gate or demonstrate a separately recorded reduction in total ownership/glue with performance parity. Keep an unqualified prototype disabled.
4. Prototype a substantial highlighting parser boundary against the pinned upstream syntax corpus and actual redraw composition. Compare complete redraws, including multiline syntax, aliases, expansions and style behavior. Require exact supported-region semantics and sanitizer checks before 50 paired redraws and the existing 20% whole-redraw improvement gate. Record unsupported cases explicitly and keep an incomplete prototype disabled.

Each hypothesis has a two-intervention or two-hour limit before auditing the premise. Scope escape requires concrete evidence that the tested boundary cannot preserve a required contract or reduce overall maintenance. Do not substitute passing helper microbenchmarks for complete-feature measurements. Retain commands, sources, identities, raw results and failures; add verifiers to the shared retained-evidence suite and commit independent slices after checks.
